# Request 008: Guided onboarding and clearer everyday use

## Goals

Improve first-use comprehension and plain-language clarity without removing planning features.

## Implemented

1. Add a five-step, dismissible first-run guided tour covering the overview, elective selection, semester planning, and course details.
2. Add a persistent top-bar “Guided tour” action so users can replay it at any time.
3. Clarify local-only storage and the need to export a backup to move a plan between devices.
4. Replace static planner instructions with descriptions that respond to Plan, Map, and List views.
5. Explain how to add a missing course to an elective group at the point of use.
6. Remove “Not reviewed” noise from elective options and neutral recommendation labels in cards/list rows.
7. Use clearer user-facing language for adding a course, course progress, planned semester, completed credits, and formal prerequisites.
8. Document the UX and preserve all existing planning, import/export, relationship, and grading capabilities.

## Verification

GitHub Actions build, tests, and deployment must be checked before claiming the change is live.
